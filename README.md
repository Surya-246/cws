PROJECT TITLE 
Math Quest – AI-Assisted Web Game Development using AWS Kiro

Objectives
Explain how Kiro accelerates development workflows through AI-powered code generation and suggestions
Use Kiro to generate boilerplate code and infrastructure templates for common AWS patterns
Evaluate when to use AI-assisted development versus traditional coding approaches
Apply AI assistance from Kiro to debug and optimize existing application code

AWS Services Used :
Amazon S3
Used for storing JSON answer files and application-related data.

AWS Systems Manager
Used for remote desktop access and management of the EC2 instance
Kiro AI Assistant

Used for:

Boilerplate generation
Infrastructure template creation
Debugging assistance
Deployment support
Code optimization
Learning Outcomes
Through this assignment, the following skills were developed:

AI-assisted software development
Cloud deployment on AWS
Infrastructure as Code concepts
Debugging cloud applications
Using S3 services
Working with JSON data storage
Understanding agentic AI development workflows
